This connects an agent written with the [Python SDK](/sdks/python) to [awp-sim](/adapters/awp-sim), the reference world. Installing awp-sim also installs the SDK. Both need Python 3.11+.

<Steps>
  <Step title="Install">
    ```bash
    pip install --pre awp-sim
    ```
  </Step>
  <Step title="Start a world">
    ```bash
    awp-sim serve
    ```
    A streaming world now listens on `ws://127.0.0.1:8710`. `awp-sim manifest` prints what it offers: one arm, `arm_01`, two observation channels, and the action types `move_to_pose` and `stop`.
  </Step>
  <Step title="Write the agent">
    ```python agent.py
    import asyncio
    from awp import ClientConnection
    from awp.aio import AsyncClient

    async def main() -> None:
        conn = ClientConnection(
            {"name": "quickstart", "version": "0.1.0", "vendor": "me"},
            consumes_modalities=["proprio/json"],
        )
        async with AsyncClient(conn, "ws://127.0.0.1:8710") as client:
            manifest = await client.initialize()                  # the world manifest
            await client.open_session("streaming", embodiment="arm_01", subscribe=["proprio"])
            await client.wait_for(lambda e: "proprio" in client.latest)

            record = await client.submit(
                "move_to_pose",
                {"pose": {"frame": "base", "p_m": [0.3, 0.2, 0.5], "q": [0, 0, 0, 1]}},
                basis=client.latest["proprio"].frame,             # what the decision rests on
                valid_for_ms=200,
            )
            print("admitted:", record.action_id)          # the record tracks every later status
            done = await client.wait_terminal(record.action_id)
            print("finished:", done.state)
            await client.close_session()

    asyncio.run(main())
    ```
  </Step>
  <Step title="Run it">
    ```bash
    python agent.py
    ```
    ```text
    admitted: a-3f9c1e0b7d2a4c58
    finished: completed
    ```
    The world reports every transition — `accepted`, `executing` with progress, `completed` — as `action.status` notifications, and writes the whole session to `./awp-audit`.
  </Step>
</Steps>

## Lockstep

Restart the world with `awp-sim serve --mode lockstep` and open the session with `"lockstep"`. Nothing moves until the agent advances time, so the loop becomes observe, submit, tick:

```python
record = await client.submit("move_to_pose", params)   # staged until the next advance
while not record.terminal:
    await client.advance(5)                            # world.tick, five advances
```
