title: "API Reference"
description: "The JSON-RPC control channel, binary frames, and canonical schemas."
---

The **control channel** is JSON-RPC 2.0; each method has a page listing params, result, errors, and examples. **Frames** on observation and command channels are a binary format. **Schemas** are generated from the canonical JSON Schemas (`schemas/v0.1/*.schema.json`).

Examples use a small grid world, `gridworld`. End-to-end sequences are in the [wire traces](/spec/wire-traces).

Conventions: requests may originate from either side; notifications have no `id`; all timestamps are `ts_mono_ns` on the session clock; all errors carry AWP codes from the [error registry](/api-reference/error-codes).
