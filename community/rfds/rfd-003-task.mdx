---
title: "RFD-003: First-class task instruction"
description: "A standard, auditable place for the language instruction that conditions the agent."
---

**Status: draft · Target: v0.2 · Area: session**

## Problem

Language-conditioned policies (VLA-class) are now a mainstream consumer of embodied interfaces. The instruction ("pick up the red block") currently has no standard home and would ride vendor extensions — invisible to tooling and the audit log.

## Proposal

A reserved `awp.task` concept: `session.open` MAY carry `task: { content: [ …content blocks… ] }` using MCP-style content blocks with Markdown default; a `task.update` control message changes it mid-session; the audit log records both. Worlds MAY surface the task to approvers alongside approval requests.

## Compatibility

Additive optional field + one new optional method, gated by capability flag `task`.
