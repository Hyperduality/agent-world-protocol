<Update label="v0.1" description="now">Draft specification published for public review as numbered [draft revisions](/community/changelog): core spec, six profiles, command channels, first-class task, the action lifecycle, safe-state timers, lockstep advancement, the reconnection cursor (`last_status_seq`), the frame extension block, clock synchronization, canonical JSON Schemas with CI validation, and validated [wire traces](/spec/wire-traces). Next milestone: the first reference implementation — a Python reference world and a scripted client — to validate the draft. Nothing is released yet: no SDKs, no awp-sim, no conformance suite.</Update>
<Update label="v0.2" description="next">Changes driven by the reference implementation and independent review. First SDK and awp-sim releases; conformance suite alpha; first registry entries.</Update>
<Update label="v1.0" description="goal">Freeze the wire format; three independent conformant implementations; foundation stewardship.</Update>
