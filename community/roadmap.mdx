<Update label="v0.1" description="now">Draft specification published for public review as numbered [draft revisions](/community/changelog): core spec, six profiles, command channels, first-class task, the action lifecycle, safe-state timers, lockstep advancement, the reconnection cursor (`last_status_seq`), the frame extension block, clock synchronization, canonical JSON Schemas with CI validation, and validated [wire traces](/spec/wire-traces). The first reference implementations validate the draft: [awp-python](/sdks/python), a Python agent SDK, and [awp-sim](/adapters/awp-sim), the reference world built on it. Their questions shaped draft revisions 4 and 5. The [conformance suite](/conformance/test-suite), published with draft 6, tests any implementation against the requirement matrix. awp-python, awp-sim, and awp-conformance are released as alphas on PyPI. A second implementation, [awp-typescript](/sdks/typescript), was written from the specification and schemas alone; what it found unclear shaped draft revision 9. The [registry](/conformance/registry) lists every configuration of each as AWP-conformant.</Update>
<Update label="v0.2" description="next">Changes driven by independent implementations and review. A world written independently of awp-sim, and bridges to existing worlds (Gymnasium, then LeRobot or ROS 2); a second embodiment in awp-sim so the reference world and the suite cover multi-bind, shared control, and the `barrier` tick authority.</Update>
<Update label="v1.0" description="goal">Freeze the wire format; three independent conformant implementations; foundation stewardship.</Update>
