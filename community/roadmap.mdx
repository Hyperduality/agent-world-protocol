<Update label="v0.1" description="now">Draft specification published for public review as numbered [draft revisions](/community/changelog): core spec, six profiles, command channels, first-class task, the action lifecycle, safe-state timers, lockstep advancement, the reconnection cursor (`last_status_seq`), the frame extension block, clock synchronization, canonical JSON Schemas with CI validation, and validated [wire traces](/spec/wire-traces). The first reference implementation, [awp-python](/sdks/python) — a Python client and the [awp-sim](/adapters/awp-sim) reference world — validates the draft; its questions shaped draft revisions 4 and 5, and the [conformance suite](/conformance/test-suite) published with draft 6 tests any implementation against the requirement matrix. awp-python and awp-conformance are released as alphas on PyPI, and the [registry](/conformance/registry) lists their first claims.</Update>
<Update label="v0.2" description="next">Changes driven by independent implementations and review. A second implementation written from the specification and schemas alone (a TypeScript SDK), and bridges to existing worlds (Gymnasium, then LeRobot or ROS 2); a second embodiment in awp-sim so the reference world and the suite cover multi-bind, shared control, and the `barrier` tick authority.</Update>
<Update label="v1.0" description="goal">Freeze the wire format; three independent conformant implementations; foundation stewardship.</Update>
