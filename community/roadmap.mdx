<Update label="v0.1" description="now">Draft specification published for public review as numbered [draft revisions](/community/changelog): core spec, six profiles, command channels, first-class task, the action lifecycle, safe-state timers, lockstep advancement, the reconnection cursor (`last_status_seq`), the frame extension block, clock synchronization, canonical JSON Schemas, and [wire traces](/spec/wire-traces). Agent SDKs for [Python](/sdks/python) and [TypeScript](/sdks/typescript), the [awp-sim](/adapters/awp-sim) reference world, and the [conformance suite](/conformance/test-suite), each in alpha.</Update>
<Update label="v0.2" description="next">Changes driven by independent implementations and review. A world written independently of awp-sim, and bridges to existing worlds (Gymnasium, then LeRobot or ROS 2); a second embodiment in awp-sim so the reference world and the suite cover multi-bind, shared control, and the `barrier` tick authority.</Update>
<Update label="v1.0" description="goal">Freeze the wire format; three independent conformant implementations; foundation stewardship.</Update>
