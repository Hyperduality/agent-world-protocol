---
title: "awp-sim"
description: "The reference world: built-in environments and the conformance target."
---

```bash
pip install awp-sim
awp-sim serve gridworld --port 8710          # lockstep grid world
awp-sim serve gridworld --mode streaming     # same world, streaming
awp-sim serve arm2d --render                 # 2D arm with envelopes + approval demo
```

Ships `gridworld`, `tictactoe`, and `arm2d`, all implementing Core + sim profiles (`arm2d` also demos envelopes, e-stop, and approval). `awp-sim` is the target every quickstart, example, and conformance assertion runs against — treat it as executable documentation.
