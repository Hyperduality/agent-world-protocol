[`awp-typescript`](https://github.com/Hyperduality/awp-typescript) (`@hyperduality/awp`) is an agent SDK for Node 20+, written from the specification and the canonical schemas alone. It targets **0.1-draft.9** and vendors that revision's schemas, frame vectors, and lifecycle table.

<Warning>
Alpha: the API changes with each draft revision. Its demo agent, `awp-demo`, is **Core Agent (lockstep): AWP-conformant against 0.1-draft.9 (awp-conformance 0.1.0a6)** and **Core Agent (streaming): AWP-conformant against 0.1-draft.9 (awp-conformance 0.1.0a6)** ([reports](https://github.com/Hyperduality/awp-typescript/tree/main/conformance)).
</Warning>

```bash
npm install @hyperduality/awp@alpha
```

## Usage

```ts
import { AwpClient } from "@hyperduality/awp";

const client = new AwpClient({
  url: "ws://127.0.0.1:8710",
  token: process.env.AWP_TOKEN,
  agent: { name: "my-agent", version: "0.1.0", vendor: "me" },
  consumesModalities: ["proprio/json"],
});
await client.initialize();                            // refuses an invalid manifest (AWP-AGT-002)
await client.openSession("streaming", { embodiment: "arm_01", subscribe: ["proprio"] });
const basis = await client.freshFrame("proprio");
const record = await client.submit(
  "move_to_pose",
  { pose: { frame: "base", p_m: [0.2, 0.1, 0.4], q: [0, 0, 0, 1] } },
  { preempt: "replace", basis, validForMs: 500 },
);
await record.settled();
await client.close();
```

In lockstep, advance explicitly: `await client.advance(1)` returns once the result and a frame of the new tick on every per-tick channel are held (AWP-TIM-003).

## What it covers

The control connection and JSON-RPC over WebSocket, manifest validation, grants, the binary and inline frame forms, per-channel loss accounting and resync, the action lifecycle and `status_seq` replay, heartbeats and clock synchronization, receiver reports, lockstep advancement, reconnection with resumption, the `ws` stream binding, and command channels. Not covered: stream bindings other than `ws`, the approver role, `session.transfer`, and the `awp.bearer.<token>` subprotocol for the credential (the client sends `Authorization`).

## Demo agent

```bash
npx awp-demo --url ws://127.0.0.1:8710 --token <token>
```

It moves the reference arm through four targets, cancels one move while it executes, and closes; it resumes after a lost connection and continues in a new session if the world no longer holds the old one.
