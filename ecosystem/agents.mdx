| Agent | Time models |
|---|---|
| `awp-demo` in [awp-python](/sdks/python) — a scripted agent that moves the reference arm, cancels a move, and triggers an envelope refusal | lockstep, streaming |
| `awp-demo` in [awp-typescript](/sdks/typescript) — a scripted agent that moves the reference arm through four targets, cancels a move while it executes, and resumes after a lost connection | lockstep, streaming |

Their conformance claims are in the [registry](/conformance/registry). To list an agent, open a pull request against this page and the registry with its `report.json` from a suite release that targets the claimed revision.
