# Contributing to Agent World Protocol

Thank you for helping improve AWP. This repository is the public documentation and draft specification.

## How to propose changes

- **Editorial fixes** (typos, broken links, wording that does not change requirements): open a pull request.
- **Normative spec changes** (new or modified `AWP-*` requirement IDs, protocol behavior): follow the [RFD process](community/rfd-process.mdx). Start with a GitHub discussion, then an RFD pull request.
