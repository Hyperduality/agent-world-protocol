title: "GUI profile"
description: "Requirements for browser and desktop environments as worlds."
---

Adds to Core:

- Channels: `screenshot` (`image/jpeg` or `image/raw`) and `dom` or `a11y_tree` (`text/event+json`) with keyframe/delta support — AWP-OBS-004
- Action types: `pointer_move`, `pointer_click`, `key_input`, `scroll`, `navigate` with normative param schemas (viewport-relative coordinates, `_px` suffix exception documented per schema)
- Streaming time model; lockstep OPTIONAL for deterministic page testing
- `requires_approval` REQUIRED for `navigate` outside an allowlist and for any credential-entry action class
